# ПР8. Ответы на контрольные вопросы

## Почему строки Вход печатаются в одном порядке, а Выход — в обратном?

Ответ: Потому что в 1-ой фазе сначала вызовы разворачиваются вниз, затем во 2-ой фазе возвращаются вверх.

## Что означает параметр depth ? Объясните, почему он показывает глубину рекурсии — количество уровней вложенных рекурсивных вызовов, а не какую-то другую величину.

Ответ: depth - целочисленное число, с помощью которого определяется кол-во пробелов. Потому что с помощью {new string(' ', depth * 2)} мы показываем сколько рекурсивных методов было выполнено.

## Почему программа завершается именно так, а не выбрасывает обычное исключение вроде FormatException , которое можно перехватить через try-catch?

Ответ: Потому что без него каждый незавершенный вызов занимал бы отдельное место в стеке вызов.
